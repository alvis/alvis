# Alvis — Ink & Marginalia Design System

> A thinking desk becoming a system map: warm paper, navy ink, watercolor pigment, and the working marks of a manuscript — crosshairs, circled keywords, margin notes, folded planes.

> **Handover contract**: Sections 10–13 (Context & Decision Log, Component Inventory & Sources, Implementation State & Next Steps, File Map) are mandatory — a zero-context agent resumes from them. Keep them current at every save point.

---

## 1. Visual Theme & Atmosphere

**Direction**: **Ink & Marginalia** — an evolution within the Editorial Watercolor identity, not a departure.

**Mood**: Personal, literary, rigorous. A visionary founder's working notebook, not a SaaS landing page. Visually stunning through editorial confidence: oversized ink-trapped serif display, real watercolor artifacts used as annotation rather than decoration.

**Canvas**: Warm paper `#F7F1E6`, single theme — there is no light/dark mode (deliberate, documented deviation from the two-tier mode contract; see §10). Content sits on raised paper `#FFF9EE`; deep sections invert to navy ink `#162747`.

**Accent Philosophy**: Oxide `#A64B2A` is the working ink of the margins — dates, circles, underlines, fold slivers. Signal blue `#466A9F`, olive, and amber appear only as watercolor pigment (washes, diagram fills, field notes). Accents are applied by hand, never generated by a dashboard theme.

**Visual Language**: Ledger and manuscript gestures — hairline rules, registration crosshairs, hand-drawn circles on keywords, handwritten Caveat notes, angular split-fold section seams. Non-negotiable identity anchors: the watercolor portrait (treatment **C · Ledger crosshairs**) and the watercolor wash background. Motion is restrained: letterpress press/lift on CTAs, one blur-to-focus route entrance, breathing washes — all killed under `prefers-reduced-motion`.

## 2. Color Palette & Roles

**Single-theme deviation**: this project ships one warm-paper theme. Tokens live under `:root[data-theme='codex']` in `src/styles/theme.css` with role names (`--color-<role>`); there is no `--theme-light-*`/`--theme-dark-*` tier and no `--ui-*` alias layer. Components consume `--color-*`/`--size-*` tokens only — zero hardcoded visual literals outside theme.css.

| Token | Role | Value |
|---|---|---|
| `--color-ink` | Headings, body text, navy fields, diagram strokes | `#162747` |
| `--color-ink-soft` | Softened ink text | `rgba(22,39,71,.78)` |
| `--color-mute` | Quiet metadata | `rgba(22,39,71,.55)` |
| `--color-mute-strong` | Supporting text, captions | `#506176` |
| `--color-accent` | Oxide — active states, dates, circles, editorial emphasis, fold slivers | `#A64B2A` |
| `--color-signal` | Slate blue — pigment accents, fold slivers, diagram fills | `#466A9F` |
| `--color-amber` | Amber — manifesto kickers, coda italic, signature marginalia | `#C9954E` |
| `--color-olive` | Olive — watercolor diagram fills only | `#5F6838` |
| `--color-paper` | Page foundation | `#F7F1E6` |
| `--color-paper-raised` | Cards, panels, mounted plates | `#FFF9EE` |
| `--color-paper-sunk` | Recessed paper areas | `#EEE5D4` |
| `--color-rule` | Hairline dividers, plate frames | `#D8C9B4` |
| `--color-rule-soft` / `--color-rule-strong` | Rule opacity steps | `rgba(216,201,180,.45/.95)` |
| `--color-on-ink` | Text on navy | `#F2E7D5` |
| `--color-on-ink-accent` | Amber-warm text on navy | `#E1A779` |

Avoid: large monochrome gradients, glossy surfaces, neon, pure black, stark white.

| Token | Value | Usage |
|---|---|---|

## 4. Component Stylings

### CTA buttons — **A · Letterpress** (locked)

```css
.cta { position: relative; z-index: 1; /* stacking context — REQUIRED or ::after paints behind ancestors */
  border: 1.5px solid var(--color-ink); border-radius: 2px;
  font: 600 .74rem/1 var(--font-family-label); letter-spacing: .05em; text-transform: uppercase;
  min-height: 44px; padding: 0 18px; transition: transform .18s ease; }
.cta::after { content: ""; position: absolute; inset: 6px -6px -6px 6px;
  border: 1px solid var(--color-accent); z-index: -1; transition: inset .18s ease; }
.cta--primary { color: var(--color-paper-raised); background: var(--color-ink);
  box-shadow: inset 0 1px 2px rgba(0,0,0,.3), inset 0 -1px 0 rgba(255,255,255,.08); }
.cta--secondary { color: var(--color-ink); background: transparent; }
.cta:hover { transform: translate(-2px, -2px); }
.cta:hover::after { inset: 9px -9px -9px 9px; }
```

Hover lifts the button toward the reader while the oxide offset frame trails behind — a plate lifting off the press. Focus: visible ring via `outline: 2px solid var(--color-signal); outline-offset: 2px`.

### Section separators — split-fold family (DesignTweaker options, locked as a set)

Base geometry (the footer's fold outline, flat plane + dominant fold ~31% + echo ~65%):

```css
--fold-clip: polygon(0 70%, 13% 70%, 31% 18%, 45% 70%, 65% 34%, 80% 70%, 100% 70%, 100% 100%, 0 100%);
```

Angular, never wavy; no blur; ≤24px deep (shorter than the footer's 30px). Three variants, all shipped as tweaker options with thickness + color knobs (polish TODO: thicker sliver steps, alternate color pairs):

| Variant | Planes above the navy front |
|---|---|
| A · Classic accents | oxide→signal hard-stop gradient sliver, solid, offset −6px |
| B · Translucent ink | ink at 16% and 40% opacity, offsets −11px/−6px |
| C · Whisper accents | oxide 38% + signal 34%, shortest (20px front) |

Reference implementation: `reviews/facelift/directions/component-separators-v3.html`.

### Manifesto band — **B + D merge**

Navy field with the real hero wash darkened almost to black behind fine paper grain (B), and hand-brushed wavy, uneven top/bottom boundaries instead of ruled edges (D). Kicker in amber caps; statement in Fraunces on `--color-on-ink`.

### Mission bridge — **A · Ink curve + arrowhead**

A single hand-drawn SVG line threading from "Give machines context" down to "Return humans to purpose", ending in a small open arrowhead. Ink stroke, no color field, no animation.

### Work entry — **B · Mounted plate**

Per project: caps kicker, Fraunces name, artifact sketch mounted in a hairline `--color-rule` frame with registration crosshairs and a "FIG. Cn" caps caption, one keyword hand-circled in oxide in the prose, a Caveat margin note. The 3-column micro-table is gone.

### Writing row — **A · Field-note thumbnail**

Each essay: small tinted watercolor field-note card (the essay's own lead art — never a repeated placeholder), title/meta right, oxide date caps, "Read the essay →". Every essay owns unique art.

### Footer coda — **B · Pigment bloom**

Navy footer unchanged in structure/copy ("Persistent enthusiast / by choice."). The real watercolor wash breathes softly behind the coda (masked radial, soft-light blend, ~8s opacity/scale loop, killed under reduced motion).

### Header — **C · Centered masthead** (every route)

Centered emblem + ALVIS wordmark; nav split either side (Home About · emblem · Now Work Thinking). Fixes the current home/interior header inconsistency. Mobile: emblem centered, nav collapses to the existing drawer.

### Cards / plates

Paper-raised background, 1px `--color-rule` border, radius 8px (4px small controls, 12px large mockup containers only). Depth is paper-like: subtle shadow `0 10px 30px rgba(22,39,71,.1)` for mounted plates only.

## 5. Layout Principles

- **Max content width**: 1140px (`--breakpoint-xl`); reading measure `38rem`.
- **Spacing**: existing rhythm tokens (`--rhythm`, `--rhythm-2: 1.625rem`, `--rhythm-4: 4rem`, `--shell-px/py` clamps). Keep 4/8px alignment.
- **Composition**: editorial and asymmetric; no two consecutive sections share a layout. Dividers (hairlines + split-folds) do the structural work — avoid heavy boxed sections.
- **Radius roles**: 4px controls · 8px cards/panels · 12px large containers. Hand-drawn circles/ellipses are SVG, not border-radius.
- **Media budget**: ≤2 non-nav raster images per route; after that, inline SVG or CSS artwork.

## 6. Depth & Elevation

Paper-like only. Shadows are single-theme constants:

| Role | Value |
|---|---|
| Mounted plate / mockup card | `0 10px 30px rgba(22,39,71,.1)` |
| Letterpress inset (primary CTA) | `inset 0 1px 2px rgba(0,0,0,.3), inset 0 -1px 0 rgba(255,255,255,.08)` |

No glossy shadows, glass, bokeh, or nested card stacks. Watercolor washes may sit behind diagrams but never reduce legibility.

## 7. Do's and Don'ts

### Do
1. Consume only `--color-*`/`--size-*`/`--font-family-*` tokens — zero hardcoded visual literals in components.
2. Keep the watercolor portrait (ledger-crosshair treatment) and wash background — non-negotiable anchors.
3. Use real content in every specimen and mock — never lorem ipsum.
4. Set `z-index: 1` on any element carrying a negative-z pseudo (letterpress frame) — otherwise it paints behind ancestor backgrounds.
5. Use SVG bezier paths for organic curves; clip-path polygons only for angular folds.
6. Keep marginalia sparse — one circled keyword, one margin note per view maximum.
7. Respect `prefers-reduced-motion` on every animation (wash breathing, letterpress lift, route entrance).
8. Keep ≥44px touch targets and visible focus rings on all interactive elements.

### Don't
1. No light/dark toggle — single theme is a locked decision.
2. No wavy/tidal section separators — the fold family is angular (user-rejected wavy twice).
3. No stock or repeated blog thumbnails — every essay owns its art.
4. No more than 3 motion types per page; nothing bounces.
5. No oversized type in compact cards/controls; no marketing compression of copy.
6. Don't replace the portrait or the glasses emblem.
7. Don't exceed the 2-raster-per-route budget.
8. Don't ship the DesignTweaker panel to production builds.
