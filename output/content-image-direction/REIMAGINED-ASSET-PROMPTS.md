# Reimagined asset prompt set

Mode: built-in `imagegen`, using the selected style card only as a material and
palette reference. Every image was composed from the essay argument rather than
from the website's previous image.

## Shared direction

Create an entirely new editorial illustration from the ground up. Echo the
site's concise conceptual project-plate language: one legible system diagram,
sparse nodes, paths, loops or layers, generous warm-ivory paper, tactile
watercolor and pencil, and subtle registration marks. Use a 16:9 landscape.
Include no text, letters, numbers, logos, UI screenshots, photorealism, or
generic abstract washes.

## Content compositions

- **Configuration Should Have a Memory** — a source-of-truth configuration
  plate fans into project plates, with local overrides and a verified release
  path.
- **The Context Layer Is the Product** — history, people, constraints,
  evidence, and unfinished decisions converge on a decision surface while
  provenance stays visible.
- **Why Agent Demos Break in Production** — memory, tools, guardrails, and
  feedback surround a delegation loop with draft, ask, stop, act, and recovery
  branches.
- **Designing Tools That Disappear Into the Work** — a studio recedes around a
  clear path from human intention to defensible work, surfacing state only where
  judgment is required.
- **On the Context Harness** — a deliberately small model sits inside a larger
  apparatus of archive, retrieval, tools, policy, and stopping logic.
- **A Harness in Eighty Lines** — one readable page contains four connected
  stations: call, route, curate, and stop, plus a refusal gate and return path.
- **The Polite Agent** — a human and agent collaborate at a shared workbench;
  the agent pauses at a fork where it can ask, prepare, wait, or act.
- **Portraits** — preserve Alvis's identity while creating a new scene for each
  system: curating layers, tracing evidence, measuring a decision, pausing at a
  threshold, or assembling accountable work.

## Asset-system translations

- **16 · Memory Stratigraphy** — archival strata, geological cross-sections,
  contour lines, and remembered decisions.
- **17 · The Provenance Loom** — stitched threads, evidence nodes, and visible
  source-to-outcome traces.
- **18 · The Human Measure** — drafting instruments, measurement grids, hands,
  and visible human judgment.
- **20 · The Calibrated Pause** — sparse thresholds, verification gates,
  arrested motion, and deliberate negative space.
- **Accountable Craft** — layered paper, traceable thread, human instruments,
  and small decision gates in one tactile system.
- **Context Looming / Being Human for Future** — a new synthesis of provenance
  threads and human agency. Context forms a large, inspectable loom behind the
  work; people retain the steering line as paths continue toward an open future.
  Indigo and rust carry evidence and decisions, while olive marks the paths a
  person can still choose.
